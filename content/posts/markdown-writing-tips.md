# 高效写作的 Markdown 技巧

Markdown 诞生于 2004 年，如今已成为技术写作领域的事实标准。它让你专注于内容本身，而不是排版格式。

## 标题层级

标题用 `#` 号表示层级，建议文章中最多用到三级标题（`###`），层级过深会让读者迷失：

```markdown
# 一级标题（文章主题）
## 二级标题（主要章节）
### 三级标题（细分小节）
```

> **技巧**：写完文章后，检查标题层级是否清晰——一篇好文章的标题大纲本身就应该能传达核心信息。

## 强调文字

```markdown
**粗体**用于强调关键词
*斜体*用于书名、术语、外来词
~~删除线~~表示已过期或错误的内容
==高亮==（部分渲染器支持）
```

效果：**粗体**、*斜体*、~~删除线~~

## 列表的正确用法

**无序列表**——用于没有顺序关系的条目：

- 苹果
- 香蕉
- 橙子

**有序列表**——用于有明确顺序的步骤：

1. 打开终端
2. 切换到项目目录
3. 运行 `npm install`
4. 运行 `npm run dev`

**嵌套列表**——子项用两个空格或 Tab 缩进：

- 前端技术
  - Vue 3
  - React
  - Svelte
- 后端技术
  - Node.js
  - Python
  - Go

## 链接与图片

```markdown
<!-- 内联链接 -->
[链接文字](https://example.com)

<!-- 带标题的链接（鼠标悬停显示） -->
[Nuxt 官网](https://nuxt.com "Nuxt - The Web Framework")

<!-- 图片（格式同链接，前加 !） -->
![替代文字](/images/photo.jpg)

<!-- 图片链接 -->
[![图片描述](/images/photo.jpg)](https://example.com)
```

## 代码块的最佳实践

行内代码用于短命令或变量名：`npm install`、`const x = 1`

代码块要指定语言，这样渲染器才能做语法高亮：

````markdown
```javascript
function greet(name) {
  return `Hello, ${name}!`
}
```
````

常用的语言标识符：`javascript`、`typescript`、`python`、`bash`、`sql`、`yaml`、`json`、`html`、`css`、`vue`

## 写作习惯建议

1. **先列大纲**：用标题把文章骨架搭好，再填充内容
2. **一次只写一件事**：每篇文章围绕一个核心主题
3. **多用例子**：抽象概念用具体代码或比喻来解释
4. **写完再改**：初稿先写完，不要边写边纠结用词
5. **读者视角**：想象你的读者是谁，他们已经知道什么

> 写作是最好的思考方式。当你能把一件事清楚地写出来，说明你真的理解了它。
